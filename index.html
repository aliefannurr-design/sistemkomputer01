Buka Pelajaran

Ringkasan Klasifikasi Perangkat Komputer SMP:

INPUT

Memasukkan data / perintah. (Mouse, Keyboard, Scanner, Mic, Touchscreen, Barcode Reader)

PROSES

Mengolah & memproses data. (CPU/Processor, RAM, Motherboard, VGA/GPU)

OUTPUT

Menampilkan hasil olahan. (Monitor, Printer, Speaker, Proyektor, Headphone)

STORAGE

Menyimpan data (permanen/sementara). (HDD, SSD, Flashdisk, SD Card, CD/DVD)

Peripheral

Perangkat tambahan/pendukung luar. (Router Wi-Fi, UPS, Bluetooth Dongle, TV Tuner)
